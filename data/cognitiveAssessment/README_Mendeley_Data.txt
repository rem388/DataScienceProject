Mendeley Data – Cognitive Assessment Questionnaire Dataset

DATASET CONTENT
This repository contains anonymized questionnaire responses collected using a
Cognitive Assessment Questionnaire (25 items) and a separate processed dataset
containing the supplied categorical outputs for Forgetfulness, Distractibility,
and False Triggering.

FILES
1. Cognitive_Assessment_Anonymized_Responses.csv
   Anonymized participant-level questionnaire and selected demographic variables.
   Direct identifiers, timestamps, address, email, and free-text achievements
   have been excluded from this publication version.

2. Cognitive_Assessment_Anonymized_Responses.xlsx
   Excel version of the anonymized response dataset.

3. Cognitive_Assessment_Processed_Data.csv
   The filtered/processed questionnaire responses and the three categorical
   fields present in the supplied filtered dataset.

4. Data_Dictionary.csv
   Variable names, types, descriptions, and response coding.

QUESTIONNAIRE SCORING
The supplied questionnaire document states that the 25 individual item ratings
can be summed to produce a total Cognitive Failures Questionnaire score from
0 to 100. It also describes three dimensions: Forgetfulness, Distractibility,
and False Triggering. The item groupings and scoring information are documented
in the accompanying questionnaire source; this dataset does not introduce a
new scoring rule beyond the supplied processed categories.

RESPONSE CODING
Each questionnaire item is coded 0–4:
  0 = Never
  1 = Very rarely
  2 = Occasionally
  3 = Quite often
  4 = Very often

DATASET SIZE
1,399 participant records are included in the supplied filtered dataset.

ANONYMIZATION NOTE
The publication files intentionally exclude direct identifiers and free-text
fields that may contain identifying information. Before public release, the
researcher should confirm that the remaining demographic combinations are
appropriate for open data sharing and that participant consent/ethics approval
permits public deposition.
